[desc="A description of functions available in the Couchdb Library"]
== The Couchdb Library

Namespace: `model://perspectives.domains#Couchdb`.

The Couchdb library provides functions for managing CouchDB databases, users, and replication, as well as for managing locally stored models and performing queries on instance storage.

NOTE: Several functions require elevated CouchDB privileges. The required level is noted for each function: _SERVERADMIN_ (full server administrator), _DATABASEADMIN_ (administrator of a specific database), or _WRITINGMEMBER_ (write access to the database).

=== CreateCouchdbDatabase

`CreateCouchdbDatabase( <databaseUrl>, <databaseName> )`

Creates a new CouchDB database. Fails silently if either argument is missing. Requires _SERVERADMIN_ access.

[cols="1,1,4"]
|===
|Parameter/Result |Type | Explanation

|databaseUrl|String|The base URL of the CouchDB server (e.g. `"https://myserver.com/"`).
|databaseName|String|The name of the database to create.
|===

[source,perspectivesarc]
----
callEffect cdb:CreateCouchdbDatabase( ServerUrl, DatabaseName )
----

=== CreateEntitiesDatabase

`CreateEntitiesDatabase( <databaseUrl>, <databaseName>, <namespace> )`

Creates a new CouchDB database and installs all standard design document views (role view, context view, pending invitations view, etc.) needed to query Perspectives entity instances. Also creates a `TheWorld` context instance in the new database.  Requires _SERVERADMIN_ access.

[cols="1,1,4"]
|===
|Parameter/Result |Type | Explanation

|databaseUrl|String|The base URL of the CouchDB server.
|databaseName|String|The name of the database to create.
|namespace|String|The namespace/domain used to construct the public URL of the database (e.g. the domain used in `public Visitor at <location>` declarations).
|===

[source,perspectivesarc]
----
callEffect cdb:CreateEntitiesDatabase( ServerUrl, DatabaseName, Namespace )
----

=== RefreshRecoveryPoint

`RefreshRecoveryPoint( <databaseName>, <lastSeq> ) returns String`

Records the current sequence number of a CouchDB database as a recovery point. This can later be used with `RecoverFromRecoveryPoint` to re-process changes since that point.

[cols="1,1,4"]
|===
|Parameter/Result |Type | Explanation

|databaseName|String|The name of the CouchDB database.
|lastSeq|String|The last known sequence number (may be empty; an empty string means start from the beginning).
|result (functional)|String|The new sequence number recorded as the recovery point.
|===

[code]
----
callExternal cdb:RefreshRecoveryPoint( DatabaseName, LastSeq ) returns String
----

[[couchdb-remove-model-from-local-store]]
=== RemoveModelFromLocalStore

`RemoveModelFromLocalStore( <versionedModelURI> )`

Removes a model from the local installation. Schedules removal of:

* the model's root context (its `on exit` can be used for model-specific cleanup; it runs while the model's indexed resources still exist);
* each indexed context of the model, together with the instances of `sys:PerspectivesSystem$IndexedContexts` and `sys:PerspectivesSystem$StartContexts` that it fills;
* each indexed role of the model, together with the instances of `sys:PerspectivesSystem$IndexedRoles` that it fills.

At the very end of the transaction, the DomeinFile itself is removed from the local models database, together with the inverted queries, downstream state notifications and automatic effects that the model contributed to other models. The argument may be a versioned or unversioned model URI.

Other instances of types defined in the model are not removed automatically. Remove them in the `on exit` of a context that is removed (for example with `delete context bound to ...`), otherwise visiting such an instance later will install the model again.

[cols="1,1,4"]
|===
|Parameter/Result |Type | Explanation

|versionedModelURI|String|The (versioned or unversioned) model URI of the model to remove.
|===

[source,perspectivesarc]
----
callDestructiveEffect cdb:RemoveModelFromLocalStore( ModelUri )
----

=== UpdateModel

`UpdateModel( <modelName>, <dependencies> )`

Updates an already-installed model to its latest version from the repository. Does not install the model if it is not yet present in the local store. Also updates stored queries and clears the query cache.

[cols="1,1,4"]
|===
|Parameter/Result |Type | Explanation

|modelName|String|The stable, versioned model URI of the model to update.
|dependencies|String|`"true"` to also update the model's dependencies; `"false"` to update only the model itself.
|===

[source,perspectivesarc]
----
callEffect cdb:UpdateModel( ModelUri, "true" )
----

=== RoleInstances

`RoleInstances( <roleType> ) returns RoleInstance`

Retrieves all instances of a particular role type from both the CouchDB entities database and the role cache. Also returns instances of roles that use the given type as an Aspect.

[cols="1,1,4"]
|===
|Parameter/Result |Type | Explanation

|roleType|String|The fully qualified enumerated role type name (e.g. `"model://perspectives.domains#System$PerspectivesSystem$User"`).
|result|RoleInstance|All instances of the given role type (may return multiple values).
|===

[code]
----
callExternal cdb:RoleInstances( "model://perspectives.domains#System$PerspectivesSystem$User" ) returns RoleInstance
----

The following example shows a typical use, where a calculated user role collects all system user instances:

[source,perspectivesarc]
----
user: Users = callExternal cdb:RoleInstances( sysUser ) returns: model://perspectives.domains#System$PerspectivesSystem$User
----

=== AddCredentials

`AddCredentials( <url>, <userName>, <password> )`

Adds CouchDB credentials for a server URL to the current session and to the user's local persistent storage. These credentials will be retrieved automatically on each subsequent session. The username may include a storage scheme prefix, which is discarded.

NOTE: This function causes a change in `PerspectivesState` but does not affect the Perspectives Universe.

[cols="1,1,4"]
|===
|Parameter/Result |Type | Explanation

|url|String|The URL of the CouchDB server to associate the credentials with.
|userName|String|The CouchDB username (the storage scheme prefix, if any, is ignored).
|password|String|The password.
|===

[source,perspectivesarc]
----
callEffect cdb:AddCredentials( ServerUrl, UserName, Password )
----

=== ClearAndFillInvertedQueriesDatabase

`ClearAndFillInvertedQueriesDatabase()`

Clears the inverted queries database and re-populates it from all locally installed models. This is a maintenance operation, useful after migrating or repairing the local installation.

NOTE: This function takes no explicit arguments.

[cols="1,1,4"]
|===
|Parameter/Result |Type | Explanation

|_(no parameters)_| |Operates on the locally installed models database.
|===

callEffect cdb:ClearAndFillInvertedQueriesDatabase()
